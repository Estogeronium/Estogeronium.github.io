# Хрон

Хронометраж текста для озвучки — https://hron.vonzvyagin.ru

Считает, сколько секунд займёт текст, с учётом того, как диктор произнесёт
числа, проценты, даты, время, телефоны, валюты, единицы, аббревиатуры и
сокращения. Плюс символы с пробелами и без, слова и слоги.

Статичная страница без сборки и бэкенда, всё считается в браузере.

## Файлы

- `index.html` — интерфейс (стили и скрипт инлайн)
- `hron.js` — движок: нормализация текста → слоги → секунды
- `favicon.svg`
- `CNAME` — домен `hron.vonzvyagin.ru`

## Как считается

1. Текст переводится в произносимый вид (`normalize`): «15%» → «пятнадцать
   процентов», «с 1.11.2026» → «с первого ноября две тысячи двадцать шестого
   года», «МГУ» → «эм-гэ-у», «т.е.» → «то есть». Числа согласуются с
   предлогами («до 50%» → «до пятидесяти процентов») и единицами.
2. Считаются слоги — гласные (для латиницы — группы гласных).
3. Время = слоги ÷ темп + паузы (запятая 0,2 с, точка 0,4 с, абзац 0,7 с;
   паузы сжимаются пропорционально темпу).

Темп по умолчанию — 5 слогов/с: на обычном тексте без цифр совпадает с
правилом «2 слова = 1 секунда».

Проверить движок из консоли:

```bash
node -e 'console.log(require("./hron.js").analyze("Скидки до 50% до 30.11").spoken)'
```
